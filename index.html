METHODOLOGY

How to read these benchmark results

20 prompts, seven categories

Six reasoning, four math, three coding, two backend, two instruction-following, two honesty, and one long-context task. Each graded answer has equal weight. Accuracy is recorded passes divided by graded answers; ungraded answers are excluded.

Recorded grades, full evidence

Scores retain the original run's automatic grades. The checkers use numbers, keywords, formatting rules, and one executed interval-merging example; they can accept incorrect or incomplete answers. Inspect the answers and references before drawing conclusions.

Timing and throughput differ

Response time is wall-clock duration per prompt. Generation throughput is the mean recorded tokens per second, not time to first token. Output lengths and model defaults vary. The long-context task can increase the configured context window.

A local snapshot, not a universal ranking

Only the latest complete 20-question run for each model is shared. Hardware and settings appear below; exact model digests were not recorded. A model tag, especially :latest, can change. These results are descriptive and are not a controlled scaling experiment.

Download the complete recorded results or reproduce the benchmark from source. This community project is not affiliated with Ollama or any model provider.
